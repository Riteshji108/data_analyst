# Customer Churn & Retention Analysis

## Business objective
Understand customer churn patterns and identify customer segments with elevated retention risk.

## Stack
Python • Pandas • NumPy • Matplotlib • Seaborn • Power BI

## Analysis
- Data quality checks
- Missing-value and duplicate handling
- Exploratory data analysis
- Churn-rate analysis
- Retention-rate analysis
- Customer segmentation
- Revenue exposure analysis
- Visual analysis of churn drivers

## Dashboard KPIs
- Customer Count
- Churn Rate
- Retention Rate
- Revenue at Risk
- Churn by Segment
- Churn Trend

## Workflow
1. Load customer-level data with Pandas.
2. Validate and clean the dataset.
3. Explore distributions and relationships with NumPy and visualizations.
4. Identify churn patterns by customer attributes.
5. Export analytical tables for Power BI.
6. Build a recruiter-friendly retention dashboard.

## Reproducibility
Synthetic customer data is used for demonstration. No fictional business results are claimed as real-world achievements.

## Files
- `data/customers.csv` — synthetic customer dataset
- `notebooks/churn_analysis.ipynb` — analysis notebook
- `python/generate_data.py` — reproducible dataset generator
