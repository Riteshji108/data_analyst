# Expense Tracker & Financial Analytics

## Objective
Build a lightweight Python expense tracker that converts day-to-day transaction records into useful monthly and category-level financial summaries.

## Stack
Python • SQL • Git • GitHub

## Features
- Add income and expenses
- Validate transaction input
- Categorize expenses
- Store structured transaction data
- Monthly summaries
- Category-wise spending analysis
- Income vs expense comparison
- Basic savings calculation

## Analytics
The project demonstrates how an operational Python script can become a small analytics workflow: capture → validate → store → query → summarize → visualize.

## Reproducibility
Use sample/synthetic transactions for demonstration. Personal financial information should never be committed to the repository.

## Suggested structure
- `src/expense_tracker.py` — application logic
- `sql/analytics.sql` — reporting queries
- `data/sample_transactions.csv` — safe demo data
- `README.md` — documentation
